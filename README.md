# IDEEZA Builders Cohort

Front-end demo of the IDEEZA Builders Cohort. The home page walks through the idea in one strip: join, do challenges, earn points, refer friends, then unlock gifts and the internship. Challenge cards use pack rarities (Common, Rare, Epic, Legendary) plus a shiny Golden Ticket. No backend and no AI. Mock data is stored in `localStorage`. Rewards are gifts only: platform access, design credits, and printed IDEEZA hardware.

```bash
npm install
npm run dev
```
